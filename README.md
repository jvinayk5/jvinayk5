## :wrench: What I work on

- **Cloud infrastructure:** AWS networking and compute (VPC, EC2, EKS, ECR, ALB, RDS, Route 53, Auto Scaling) provisioned with Terraform modules, remote state and separate Dev/QA/Production environments.
- **CI/CD:** Jenkins pipelines covering build, SonarQube quality checks, Docker image creation, security scanning and deployment.
- **Containers:** microservices on AWS EKS with Deployments, Services, ConfigMaps, Ingress, HPA, rolling updates and rollbacks.
- **Event-driven systems:** MSK/Kafka, EventBridge Pipes, SQS, Lambda and Aurora MySQL, with DLQs, retries and visibility-timeout strategies.
- **Observability:** CloudWatch, SNS, Prometheus and Grafana dashboards and alerts.
- **Security:** least-privilege IAM, private-subnet Lambda with VPC endpoints, Secrets Manager and KMS.
